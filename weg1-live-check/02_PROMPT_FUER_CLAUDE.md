## Regeln

1. Zuerst `tabs_context_mcp`, dann **eigene neue Tabs** öffnen. Meine bestehenden Tabs nicht anfassen. Am Ende deine Tabs schließen.
2. **Keine** Formulare absenden, keine Anmeldung, kein Login, keine Käufe, keine Anzeigen anklicken. Fragt eine Seite nach Login oder Zahlung: überspringen und notieren.
3. **Captcha / „ungewöhnlicher Datenverkehr“ / Fehler nach 2 Versuchen:** sofort stoppen und mich fragen. Nicht umgehen.
4. Menschliches Tempo: zwischen zwei Google-Suchen ein paar Sekunden Pause.
5. ChatGPT: **temporären Chat** verwenden. Bei Gemini und Perplexity: für jede Frage einen **neuen Chat**.
6. Nur notieren, was du siehst. Unklar → „unklar“ schreiben.
7. Schreibe Zwischenergebnisse nach jedem Block (A, B, C, D) fest, damit nichts verloren geht, wenn die Verbindung abbricht.

## Block D – Technik-Check pagecompliance.de

Öffne `https://pagecompliance.de` und dann, soweit vorhanden, /preise, /ueber-uns, Blog, FAQ (Links aus der Navigation nehmen). Für **jede** dieser Seiten mit `javascript_tool` auslesen:

```js
(() => {
  const m = n => document.querySelector(`meta[name="${n}"]`)?.content ?? null;
  return {
    url: location.href,
    title: document.title,
    description: m('description'),
    robots: m('robots'),
    canonical: document.querySelector('link[rel=canonical]')?.href ?? null,
    lang: document.documentElement.lang,
    h1: [...document.querySelectorAll('h1')].map(e => e.innerText.trim()),
    h2: [...document.querySelectorAll('h2')].map(e => e.innerText.trim()).slice(0, 15),
    jsonld: [...document.querySelectorAll('script[type="application/ld+json"]')].map(s => s.textContent.slice(0, 1500)),
    og_title: document.querySelector('meta[property="og:title"]')?.content ?? null,
    hreflang: [...document.querySelectorAll('link[rel=alternate][hreflang]')].map(l => l.hreflang + ' ' + l.href)
  };
})()
```

**Server-Rendering prüfen** (wichtig: KI-Crawler führen oft kein JavaScript aus). Auf der Startseite ausführen:

```js
fetch(location.href, {cache: 'no-store'}).then(r => r.text()).then(html => ({
  rohHTML_laenge: html.length,
  h1_im_rohHTML: /<h1[\s>]/i.test(html),
  textprobe_rohHTML: html.replace(/<script[\s\S]*?<\/script>/gi, '').replace(/<style[\s\S]*?<\/style>/gi, '').replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim().slice(0, 600),
  sichtbarer_text_laenge: document.body.innerText.length
}))
```

Wenn `textprobe_rohHTML` fast leer ist, der sichtbare Text aber lang: Inhalte werden **nur per JavaScript** geladen. Das ist ein kritischer Befund.
